# 01. 구현 요소

게임에 들어 있는 기능을 정리한 문서임. [← README](../README.md)

## 게임 규칙 요약
- 강아지 다마고치를 0살부터 키우며, 선택지를 하나 고를 때마다 한 턴이 지나고 계절이 바뀜.
- 계절은 봄 → 여름 → 가을 → 겨울 순서이고, 겨울 다음 봄이 될 때 나이가 1살 늘어남.
- 10살이 되면 게임이 끝나고, 그 전에도 조건이 맞으면 엔딩이 발생함.

## 기능 목록
| 기능 | 설명 | 구현 위치 |
| --- | --- | --- |
| 스테이터스 바 | 건강, 행복, 친밀도를 0~10으로 표시함. 시작값은 건강 7, 행복 5, 친밀도 3 | `main.py` `draw_stat_bars()` |
| 상태창 | 감기, 배고픔 같은 상태를 라벨로 나열함. 상태 8종(배부름, 배고픔, 감기, 건강함, 우울, 신남, 부상, 예방접종) | `main.py` `draw_status_window()` |
| 마우스 오버 설명 | 상태 라벨에 마우스를 올리면 매 턴 효과, 설명 문장, 남은 턴 수가 나옴 | `main.py` `show_tooltip()`, `game_logic.py` `status_description()` |
| 선택지 | 총 20개. 나이 고정, 상태 조건, 계절 조건, 나이 조건에 따라 등장함 | `data.py` `CHOICES`, `game_logic.py` `can_appear()` |
| 랜덤 등장 | 조건을 통과한 선택지 중 무작위로 하나를 뽑음. 직전 선택지는 연속 등장하지 않음 | `game_logic.py` `pick_next_choice()` |
| 나이와 계절 | 계절이 4번 바뀌면 1살 증가함 | `game_logic.py` `advance_season()` |
| 강아지 이미지 | 상황에 맞는 도트 이미지 14장 중 하나를 표시함 | `game_logic.py` `pet_image_name()` |
| 예방접종 | 보유하는 동안 감기에 걸리지 않음 | `game_logic.py` `add_status()` |
| 엔딩 6종 | 아래 표 참고 | `game_logic.py`, `data.py` `ENDINGS` |
| 돌아보기 | 엔딩 후 지금까지의 선택과 결과를 새 창에서 읽음 | `main.py` `show_history()` |

## 엔딩
| 엔딩 | 발생 조건 |
| --- | --- |
| sick | 건강이 0 이하가 됨 |
| runaway | 행복이 0 이하가 됨 |
| strayed | 친밀도가 0 이하가 됨 |
| natural_warm | 7살 이후 자연사 발생, 친밀도 7 이상 |
| natural_lonely | 7살 이후 자연사 발생, 친밀도 7 미만 |
| ten_years | 10살에 도달함 |

자연사 확률은 7살부터 계절이 바뀔 때마다 `0.06 × (나이 - 6)`이고, 건강이 7 이상이면 절반이 됨. (7살 6%, 8살 12%, 9살 18%)
